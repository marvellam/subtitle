# sample-course

This folder stores the project/profile data for subtitle proofreading.

This public sample demonstrates:

- an automatic terminology correction: `人工智会` → `人工智能`;
- safe preservation of `刚刚` and `对照`;
- contextual review of discourse words;
- blanking a block only when the whole block is a configured standalone filler.

Run Phase 1 from the repository root and write output to a temporary run directory.
